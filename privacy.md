# Privacy Policy for AI-STUDIO-FILE-STATS

## 1. Zero-Data Collection
This extension operates with a strict "zero-data" policy:
* **No Code Collection:** The extension never reads, uploads, or transfers your source code.
* **No Data Storage:** We do not collect, store, or share any personal data, analytics, or usage metrics.
* **No Telemetry:** All telemetry and tracking features are completely absent or disabled.

## 2. Local Processing
All computing, processing, and code analysis are performed entirely on your local machine. No external servers or APIs are contacted during operation.

## 3. Changes to This Policy
Any future updates to this extension will respect this zero-data policy. If any configuration requirements change, users will be explicitly notified.

## 4. Contact & Support
If you have any questions or security concerns regarding this policy, please open an issue on our official repository tracker.
